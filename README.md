Mi Dinero

App sencilla para llevar el control diario de tus ingresos y gastos, pensada para ser fácil de usar — incluso para personas con TDAH. Un solo archivo, sin instalaciones, sin cuentas, sin publicidad.

Funciona desde el navegador y se puede agregar a la pantalla de inicio del teléfono para abrirla como una app.

✨ Características
Registro rápido: una caja verde para ingresos y una roja para gastos.
Escribe monto y descripción juntos, por ejemplo 2000 salario o 150 super. La app saca el número sola.
Totales al instante: ingresos, gastos y balance (verde si es positivo, rojo si es negativo).
Historial: resumen del mes actual y los 3 meses anteriores, más la lista completa con fechas.
Copiar para WhatsApp: exporta todo con un toque, listo para pegar en un mensaje.
Empezar de nuevo: borra la lista actual pero conserva los totales por mes.
Moneda: quetzales (Q).
📲 Cómo usarla
Abre la app en Safari (iPhone) o Chrome (Android).
Toca Compartir → Agregar a inicio.
Ábrela desde el ícono. Se abre a pantalla completa, como una app.

Tus registros se guardan en tu propio teléfono. La primera vez, agrega un movimiento y vuelve a abrirla para confirmar que todo quedó guardado.

🔒 Privacidad

Todos tus datos viven solo en tu dispositivo (en el almacenamiento del navegador). No se envían a ningún servidor, no hay cuentas ni seguimiento. Si publicas tu copia, solo compartes la app vacía — nunca tus números.

🚀 Publica tu propia copia (gratis)

Con una cuenta de GitHub:

Crea un repositorio público y sube el archivo index.html.
Ve a Settings → Pages.
En Source, elige Deploy from a branch, rama main, carpeta / (root) y guarda.
En 1–2 minutos tendrás tu enlace: https://tu-usuario.github.io/mi-dinero/

Ese enlace es permanente. Ábrelo en el teléfono y agrégalo a inicio.

🛠️ Tecnología
Un solo archivo index.html — HTML, CSS y JavaScript, sin dependencias.
Guarda los datos con localStorage del navegador.
Funciona sin conexión una vez cargada.
